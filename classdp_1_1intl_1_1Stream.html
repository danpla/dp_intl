Detailed Description

Input stream.

Although the class methods use types such as size_t and int64_t, the dp_intl library will never read or position the stream beyond the first 100 megabytes. This means that if the underlying API used for a concrete Stream is limited to smaller integer types, you don't need to handle the edge cases, such as integer overflow or wrap-around.
